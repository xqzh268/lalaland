# 架构说明

[返回README](../README.md) · [开发与发布](development.md)

## 进程与职责

应用采用一个EXE的三种入口，入口由[Program.cs](../src/LaLaLand/Program.cs)分派。

| 进程 | 职责 | 边界 |
| --- | --- | --- |
| 主进程 | WinUI窗口、托盘、快捷键、歌词、音频分析、音量和设置 | 持有用户设置的写入权；媒体状态来自托管快照 |
| `--media-worker` | Windows媒体会话监听与播放控制，歌曲、时间轴、封面处理 | 持有原生SMTC对象；标准输入/输出传递逐行JSON；设置服务不持久化 |
| `--watchdog <pid>` | 等待主进程结束，判断异常退出并限次重启 | 不启动WinUI；正常退出和明确终止不重启 |

媒体原生对象回收故障隔离在子进程内；该设计不保证其他主进程原生组件永不崩溃。媒体监听连续短时间失败超过重试限额会停止监听，避免无限循环。

崩溃监护要求主进程已运行至少30秒，并限制10分钟内最多3次重启。异常标记与重启历史保存在用户数据目录，具体判断以代码为准。

## 媒体数据流

1. `App`建立托盘、快捷键与`MediaService`，按持久化显示状态创建或释放岛窗口。
2. 主进程的`MediaService.Worker`通过`MediaWorkerClient`启动监听子进程。
3. 子进程中的`MediaService`读取系统媒体会话，输出歌曲、播放/暂停、倍速、时长、位置、封面及配色快照。
4. 主进程把快照调度到UI线程；`IslandWindow.Playback`更新歌曲与时间轴，获取相应歌词。
5. 控制命令携带请求ID；子进程返回对应回复。隐藏时不存在常驻媒体监听，控制操作会临时启动子进程。

播放位置携带共享单调时钟采样点，补偿管道传输与UI调度延迟；倍速与单曲校准用于歌词时间和下一次调度。切歌时标题先到、时长后修正会重新查找歌词；普通位置更新不会重复查询。

## 歌词获取与时间模型

`LyricsService`由获取与缓存、来源适配、匹配规则三个分部组成：

- [LyricsService.cs](../src/LaLaLand/Services/LyricsService.cs)：本地优先、缓存、并发协调、取消与重试、导入。
- [LyricsService.Providers.cs](../src/LaLaLand/Services/LyricsService.Providers.cs)：网易云音乐、QQ音乐、LRCLIB、酷狗搜索与下载。Spotify官方 Web API 需要授权，本项目不保存账户令牌，Spotify播放时使用通用歌词源匹配。
- [LyricsService.Matching.cs](../src/LaLaLand/Services/LyricsService.Matching.cs)：标题、歌手、版本、时长与元数据规范化。

每个来源共享8秒预算；单次HTTP默认超时7秒。连接异常、无效JSON、HTTP 408/429/5xx最多延迟350毫秒重试一次；明确无匹配和永久错误不重试。请求取消会结束获取，失败或无匹配不持久化为空歌词。

候选先通过身份与录音版本约束，再比较匹配评分和时间轴质量。YRC为空或不可解析时回退LRC。缓存使用规范化的歌名、歌手、专辑和四舍五入后的秒级时长生成身份，当前缓存版本为3。

`LrcParser`与`YrcParser`输出统一的`Lyrics`/`LyricLine`模型，保留译文与逐字时间。`LyricCalibration`把媒体时钟变换为歌词时钟：

```text
歌词时间 = 媒体时间 × 单曲时间比例 + 单曲偏移 + 全局偏移
媒体跳转 = (歌词时间 - 单曲偏移 - 全局偏移) / 单曲时间比例
```

时间比例限制在0.9～1.1，单曲偏移限制±30秒，全局偏移限制±2秒。下一次调度间隔同时除以时间比例与播放器倍速。校准和跳转使用同一模型，避免只改高亮而不改跳转。

## 窗口、渲染与排版

| 模块 | 作用 |
| --- | --- |
| `Views/IslandWindow.*` | 固定透明宿主窗口、三态形变、播放、节拍、唱片、游戏策略与位置 |
| `Interop/IslandBackdrop` | 系统合成器与背景模糊，圆角裁剪随岛形动画同步 |
| `Controls/LyricsPanel` | 普通歌词滚动与逐行显示 |
| `Controls/LyricFlowPanel` | 唱片避让、绕排与行切换 |
| `Controls/SweepText` | 文本与逐字高亮绘制 |
| `TextShaper`、`TokenLayout`、`LyricTypography` | 字形测量、字体脚本分段与布局 |
| `LyricLayoutTransition` | 中途切句时从当前显示状态接续过渡 |
| `ArtworkProcessor`、`LyricColors` | 封面处理、渐变与透明度 |

形变和透明度尽可能在合成线程动画；窗口Region用于透明区域点穿。唱片绕排在目标视口准备换行，滚动阶段移动已准备的文字；切换、跳转和中途切句使用约380毫秒缓入缓出，静止后停止过渡计时器。纯文本绕排采用稳定避让宽度，减少文档高度与滚动相互影响。

歌词按下一行时间做单次调度，进度条使用线性动画。音频分析按需运行WASAPI进程回环捕获，失败时回退到默认播放设备，FFT结果用于频谱和节拍。音量通过播放器音频会话操作，收藏单独走UI Automation：Apple Music使用专用定位，Spotify、网易云音乐、QQ音乐、酷狗音乐在播放器窗口底部栏查找喜欢/收藏按钮（`FavoriteService`）。

## 隐藏生命周期

`App.ApplyPanelVisibility`是显示状态入口：显示时创建窗口并恢复媒体监听；隐藏时释放窗口，停止相应计时器、请求、音频分析和媒体子进程。托盘与快捷键继续通过原生消息窗口运行。

隐藏模式与窗口的收起状态不同：收起仍显示胶囊并可显示音乐信息，隐藏会拆除持续工作。新功能应明确它属于窗口生命周期还是应用生命周期，防止窗口关闭后订阅、后台任务或计时器残留。

## 设置与持久化

`SettingsService`在UI线程发出变更事件，600毫秒防抖后将JSON写入临时文件再替换目标。歌词颜色和透明度使用专门事件，避免无关的布局与播放重建。媒体子进程使用`persist:false`，不回写用户偏好。

单曲歌词导入与在线缓存同样先写临时文件再替换。设置与校准在Roaming AppData，歌词在Local AppData，路径见[使用指南](usage.md#数据存储与备份)。

`MemoryTrimmer`在启动或空闲后尝试回收未使用页面。实际CPU、GPU、工作集和延迟受窗口状态、字体、播放器与硬件影响；仓库不把某次工作集数字作为统一性能保证。
