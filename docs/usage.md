# 使用指南

[返回README](../README.md) · [故障排查](troubleshooting.md)

## 启动、展开与托盘

1. 启动`LaLaLand.exe`，在播放器中开始播放歌曲。
2. 鼠标悬停在胶囊上，查看封面、标题、进度和控制；点击卡片或歌词按钮展开完整歌词，也可使用`Ctrl+Alt+L`。
3. 拖动进度条或点击同步歌词行可请求播放器跳转，是否生效取决于播放器提供的能力。
4. 左键托盘切换面板显示；右键托盘调整位置、样式、材质和播放源，或打开设置、切换开机自启、退出。

默认停靠在主显示器顶部居中，纵向偏移10。默认启用空闲隐藏、悬停展开、歌词、翻译、逐字高亮及唱片绕排。位置、宽度、缩放和显示器可在设置中修改。

应用采用单实例运行；再次启动会请求已有实例打开设置。关闭设置窗口后仍驻留托盘，要结束应用请使用托盘→退出。

## 播放源与控制

设置→播放与音量提供系统跟随、Apple Music优先，以及 Apple Music、Spotify、网易云音乐、QQ音乐和酷狗音乐的单平台锁定：

| 模式 | 行为 |
| --- | --- |
| 优先Apple Music（默认） | 优先选择Apple Music，否则跟随系统当前媒体会话 |
| 跟随系统当前媒体 | 使用Windows报告的当前会话 |
| 仅Apple Music | 只选择Apple Music，没有相应会话时不显示其他播放器 |
| 仅Spotify / 仅网易云音乐 / 仅QQ音乐 / 仅酷狗音乐 | 只选择对应平台的Windows媒体会话；没有相应会话时不显示其他播放器 |

普通播放控制依赖Windows媒体会话。只有播放器向系统提供标题、封面或可跳转时间轴时，相应功能才可用。多个播放器同时运行时，先核对播放源。

收藏使用UI Automation点击播放器自己的喜欢/收藏按钮，支持Apple Music、Spotify、网易云音乐、QQ音乐、酷狗音乐；浏览器等其他播放器不显示收藏按钮。失败时检查播放器窗口与[排查说明](troubleshooting.md#收藏操作失败)。

音量控制仅针对当前播放器的音频会话，默认步长5%，不调整系统主音量或其他应用。实际听到的音量还受播放器内部音量影响。滚动岛上的鼠标滚轮也可调节。

## 隐藏面板待机

在设置→交互与行为启用「隐藏面板（仅保留快捷键）」，或使用托盘同名开关、`Ctrl+Alt+H`。

隐藏时销毁岛窗口，停止其动画、音频分析、歌词请求、媒体持续监听、封面处理与全屏检测。进程保留托盘和快捷键的消息循环。显示状态自动保存，下一次启动仍按保存值运行；恢复时重新读取当前媒体状态。

隐藏状态下，播放/暂停、切歌、收藏与音量快捷键按需查询或控制播放器，不会唤出岛。`Ctrl+Alt+L`只操作已显示的岛；恢复面板请使用`Ctrl+Alt+H`或托盘。

## 在线歌词与导入

在线歌词按「本地导入副本→有效在线缓存→在线匹配」的顺序获取。网易云音乐、QQ音乐、LRCLIB和酷狗音乐并发查询；Spotify等播放器的歌曲也会通过这些通用歌词来源匹配。匹配优先确认歌名、主唱、录音版本和时长，再考虑时间轴质量。Live、翻唱或混音不会仅因逐字时间轴更完整就替代原录音。

歌名中的影视附注、简繁体元数据及周杰伦/Jay Chou别名有专门匹配处理。版本和时长参与缓存身份；短暂网络失败和明确无匹配不会写入长期「无歌词」缓存。

设置→歌词→当前歌曲校准与歌词管理：

- **重新搜索**：移除当前曲目的在线缓存并发起查询。存在本地副本时该按钮禁用，先移除本地副本。
- **导入歌词**：选择`.lrc`、`.yrc`或`.txt`，单文件最多2MB；支持UTF-8、带BOM的UTF-16和GB18030。导入内容保存为应用管理的副本。
- **移除本地歌词**：移除本曲导入副本，恢复在线匹配；原始文件保留。
- **清除缓存**：删除在线歌词缓存，保留本地副本和单曲校准。

增强LRC与YRC可携带逐字时间轴，普通LRC通常只有逐行时间轴，TXT可作为无时间轴文本显示。来源标签会区分逐字同步、逐行同步或无时间轴，悬停可查看匹配版本和时长。

## 时间校准

先确认歌曲与录音版本正确，再调整设置→歌词中的时间校准。

| 现象 | 调整方式 |
| --- | --- |
| 所有歌曲都有固定偏差 | 调整全局偏移，范围±2000毫秒 |
| 只有本曲整首滞后 | 增加单曲偏移，正值使歌词提前，范围±30000毫秒 |
| 只有本曲整首提前 | 减小单曲偏移 |
| 越播越滞后或提前 | 固定偏移调好后再调整累计偏差，正常保持0% |

例如，单曲偏移`+500ms`使歌词提前半秒；累计偏差`+1%`表示播放到100秒时额外提前1秒。累计偏差限制为±10%，不要用它补偿固定延迟。

单曲校准按歌名、歌手、专辑和时长保存，与全局偏移叠加。点击歌词跳转使用逆向变换，播放倍速参与实际调度。更换录音版本或播放器修正时长后，可能对应新的校准身份。

## 字体、颜色与外观

设置→歌词中，中英文字体独立选择；同一句混合文字按字符选择字体。日文和韩文跟随中文字体，缺字由Windows回退。旧版单字体设置会迁移成两项初始值。

默认字体颜色来自封面流光处理后的色彩，无封面或透明封面回退白色；也可使用色盘、RGB或HEX指定自定义色。切回封面模式会保留自定义色。

- 混色程度：0%为封面统一色，100%为完整渐变，仅封面模式生效；默认100%。
- 字体透明度：0%不透明，100%完全透明；默认0%，过高会使歌词不可见。
- 原文、译文、收起歌词、普通歌词与唱片绕排都会更新；颜色和透明度调节保留逐字高亮、邻行渐隐与当前布局。

五种背景材质在设置→外观与效果选择。液态玻璃是背景模糊与高光模拟，不是光学折射。频谱与节拍效果在本机分析实际播放音频；进程音频捕获不可用时会回退到默认播放设备，其他声音可能影响节拍。

## 游戏与全屏

设置→交互与行为可选性能优化显示（默认）、仅切歌时短暂出现、游戏中隐藏或完整效果。独占全屏显示受系统合成路径影响，建议使用无边框窗口，并按需要关闭持续效果。

## 数据存储与备份

| 路径 | 内容 |
| --- | --- |
| `%APPDATA%\LaLaLand\settings.json` | 外观、快捷键、显示状态、播放源和单曲校准 |
| `%APPDATA%\LaLaLand\log.txt` | 运行与错误日志；超过约512KB后重新生成 |
| `%APPDATA%\LaLaLand\running.marker` | 主进程运行标记，用于识别上次异常结束 |
| `%APPDATA%\LaLaLand\restarts.txt` | 崩溃监护的限次重启记录 |
| `%LOCALAPPDATA%\LaLaLand\lyrics\*.json` | 在线匹配缓存，包含歌词与匹配元数据 |
| `%LOCALAPPDATA%\LaLaLand\lyrics\local\*.json` | 单曲本地导入副本 |

退出应用后备份`settings.json`与`lyrics`目录即可保留设置、校准与歌词。更换电脑时可恢复到对应目录；字体和显示器配置仍取决于新电脑。不要把运行标记作为配置恢复。

开机自启通过当前用户的`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`中`LaLaLand`项保存EXE路径。移动发布目录后，重新关闭再开启自启以更新路径。移除应用前先关闭自启，退出后再删除发布目录；是否保留用户数据由自己决定。

在线查询会发送歌曲标题、歌手、专辑和/或录音时长到对应来源。音频分析代码不保存录音文件。缓存和日志可能包含歌曲信息与路径，分享前先检查内容。
